# Dragonfyre → Native Rust / Horizon

Нативный перенос **Cisco's Fantasy Medieval RPG [Dragonfyre]** для **Horizon Offline Launcher**. Это **незавершённый проект**, а не готовая сборка.

## Для ИИ-агентов: начните здесь

Передайте агенту [ссылку на репозиторий](https://github.com/Ybuuc/dragonfyre-horizon-rust) и напишите:

> Продолжи перенос Dragonfyre с последнего опубликованного чекпоинта. Прочитай AGENTS.md и reports/AI_STATE.json, открой указанный Issue и рабочий коммит, выполни следующий шаг и сохрани новый чекпоинт в GitHub.

1. [AGENTS.md](AGENTS.md) — правила проекта и передачи работы.
2. [reports/AI_STATE.json](reports/AI_STATE.json), поле `handoff` — точка продолжения. [CURRENT_STATUS.md](CURRENT_STATUS.md) — детали и доказательства.
3. [ROADMAP.md](ROADMAP.md), [CONTEXT.md](CONTEXT.md) и отчёты `STAGE*.md` — порядок задач, ограничения и история.

Агенту нужен авторизованный доступ к приватному репозиторию. Для чтения достаточно доступа на чтение, для публикации коммита или рабочей ветки нужен доступ на запись. Агент с доступом к GitHub может работать в облаке, а запуск через Windows Horizon требует соответствующей игровой среды.

## Важное

- Полный нативный Rust-порт, а не запуск Forge/Java.
- Сохранить механики, квесты, предметы, магию, бои, контент и интеграции оригинала.
- Запуск из **обычного окна Horizon Offline Launcher → Dragonfyre → Играть**.
- Не выдавать частичное содержимое или сборку без аудио за завершённый порт.
- Существующий профиль `%APPDATA%\horizon\instances\dragonfyre` и миры нельзя перезаписывать или удалять.

## Текущее состояние репозитория

- Исходники Rust-модулей, квестового движка, mixins, Python/PowerShell-скриптов и документация **уже находятся в GitHub**. Чистый `git clone` автономного Rust-ядра был проверен: `34/34` unit tests с Rust 1.99.1.
- Применение 8 mixin-инъекций и 3 модулей подтверждено; Debug-клиент Horizon собран, `exit_code=0`, SHA-256 совпал с отчётом. **Игровой запуск этой Debug-сборки ещё не подтверждён.**
- Не все временные рабочие деревья и внешние ресурсы включены в Git: 27 неотслеживаемых папок требуют завершения аудита, `outputs/` и большие артефакты намеренно исключены. Не считать GitHub полной копией всех бинарников и стороннего Horizon.
- Для нового ИИ без предыдущей переписки — [`reports/AI_STATE.json`](reports/AI_STATE.json) и [`docs/AI_ACCESS.md`](docs/AI_ACCESS.md). Обновления по сборкам публикуются безопасной сводкой через `scripts/sync-ai-state.ps1 -Push`.
