# Dragonfyre → Native Rust / Horizon

Нативный перенос **Cisco's Fantasy Medieval RPG [Dragonfyre]** для **Horizon Offline Launcher**. Это **незавершённый проект**, а не готовая сборка.

## Для ИИ-агентов: начните здесь

1. Прочитайте [AGENTS.md](AGENTS.md) — обязательный порядок работы и правила доказательств.
2. Прочитайте [CURRENT_STATUS.md](CURRENT_STATUS.md) — последний подтверждённый по переданным материалам статус.
3. Сверьте [ROADMAP.md](ROADMAP.md) с реальным исходным планом в локальном проекте и отчётами этапов.
4. Прочитайте [CONTEXT.md](CONTEXT.md) и `STAGE*.md` после загрузки исходников.
5. Проверьте исходники, конфигурацию, журналы испытаний и Git history **до** следующей задачи.

## Важное

- Полный нативный Rust-порт, а не запуск Forge/Java.
- Сохранить механики, квесты, предметы, магию, бои, контент и интеграции оригинала.
- Запуск из **обычного окна Horizon Offline Launcher → Dragonfyre → Играть**.
- Не выдавать частичное содержимое или сборку без аудио за завершённый порт.
- Существующий профиль `%APPDATA%\horizon\instances\dragonfyre` и миры нельзя перезаписывать или удалять.

## Статус импорта

На момент создания репозитория сюда загружена **документационная основа**, а **исходники с Windows-диска ещё не импортированы**. До проверки локальных файлов и импорта нельзя считать этот репозиторий полной копией рабочего дерева.

Из прошлой сессии известен рабочий путь:

`C:\Users\Dimash\Documents\Codex\2026-11-06\new-chat-4\work\dragonfyre`

Именно его нужно сопоставить с импортом.
